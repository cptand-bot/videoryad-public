# МАНИФЕСТ БОЕВОГО КОДА — что разрешено раскатывать в облако (2026-10-23)
#
# Зачем. Второй сборщик (арсенал, `fullcycle/`) разрабатывается ОТДЕЛЬНОЙ
# вкладкой, и его код в боевую сборку попадать не должен. Единственная дорога,
# по которой он туда физически может попасть, — файл, положенный в
# `template/` или `cloud/`: `sync_assembler.sh` раскатывает ЭТИ ДВЕ ПАПКИ на
# все восемь целей, и с этого момента новый код работает в каждом ролике.
#
# Как работает. Перед раскаткой `sync_assembler.sh` сверяет содержимое
# `template/` и `cloud/` с этим списком. Нашёл файл, которого здесь нет, —
# раскатка ОСТАНОВЛЕНА, файл назван. Разработка арсенала при этом ничем не
# ограничена: в `fullcycle/` клади что угодно, туда предохранитель не смотрит
# и в облако оно не едет.
#

# одной строкой — это осознанное действие диспетчера, а не формальность.
